
# Diploma DevOps Application (dip-app)

Тестовое статическое веб-приложение на базе Nginx Alpine для дипломного практикума.

## Ссылки на артефакты
* **Docker Hub Registry:** [datadynamo/dip-app](https://hub.docker.com/r/datadynamo/dip-app)
* **Текущая версия:** `v1.0.0`

## Локальный запуск
```bash
docker run -d -p 8080:80 datadynamo/dip-app:v1.0.0
```
